# FORMA Hotel — WordPress-тема-снимок

Это отдельная устанавливаемая classic-тема WordPress, которая воспроизводит текущий статический сайт. Статический HTML/CSS/JS-сайт в корне репозитория остаётся эталоном и продолжает использоваться для текущих правок и показа клиенту.

Готовый архив: `wordpress-theme/dist/forma-hotel.zip`.

## Как обновлять тему

1. Внести визуальные и текстовые правки в текущие HTML-файлы и `assets/` статического сайта.
2. При изменении общей WordPress-оболочки отдельно поправить ручные файлы темы.
3. Из корня проекта выполнить:

   ```powershell
   npm run build:theme
   ```

Команда сама:

- заново создаёт PHP-снимки страниц и копирует актуальные assets;
- запускает структурные тесты и проверяет ZIP;
- устанавливает ZIP в изолированный WordPress Playground;
- проверяет страницы и интерактивность через Playwright на ширинах 1280, 360 и 320 px;
- заменяет `dist/forma-hotel.zip` только после успешного прохождения всех проверок.

Не редактировать вручную `front-page.php`, `404.php`, `page-*.php`, `inc/generated-routes.php` и содержимое `forma-hotel/assets/`: при следующей сборке они будут созданы заново.

Ручные части темы:

- `forma-hotel/header.php` — общий header и оба меню;
- `forma-hotel/footer.php` — общий footer;
- `forma-hotel/template-parts/lead-dialog.php` — модальная форма;
- `forma-hotel/template-parts/cookie-controls.php` — Cookie-баннер;
- `forma-hotel/functions.php` — подключение ресурсов, SEO-метаданные и WordPress hooks;
- `forma-hotel/inc/theme-setup.php` — безопасное создание страниц и меню;
- `forma-hotel/style.css` — метаданные темы и только WordPress-специфичные стили.

Маршруты и связь с исходными HTML-файлами описаны в `route-manifest.mjs`. Генератор запускается напрямую командой `node wordpress-theme/scripts/generate-wordpress-theme.mjs`, но готовый архив следует обновлять только полной командой `npm run build:theme`.

## Установка в WordPress

Требования: WordPress 6.4 или новее, PHP 8.1 или новее.

1. В админке открыть «Внешний вид → Темы → Добавить тему → Загрузить тему».
2. Выбрать `forma-hotel.zip`, установить и активировать.
3. После активации проверить главную страницу и меню.

При первой активации тема:

- создаёт только отсутствующие страницы из маршрутной карты;
- выстраивает родительскую структуру;
- назначает главную страницу;
- включает ЧПУ `/%postname%/`, только если используются стандартные «простые» ссылки;
- создаёт или дополняет меню `FORMA Primary` и назначает его в область `primary`;
- не удаляет и не перезаписывает существующие страницы или материалы;
- повторно запускается без дублирования страниц и пунктов меню.

Если на сайте уже есть страница с тем же полным путём, тема сохраняет её как есть. Перед установкой на непустой рабочий сайт всё равно нужен резервный снимок базы и файлов.

## Ограничения текущей версии

Это точный презентационный снимок, а не финальная динамическая CMS-модель:

- формы валидируются в браузере, но пока не отправляют заявки;
- аналитика, CRM, почтовая отправка и антиспам не подключены;
- кнопки социальных сетей остаются заглушками до получения ссылок клиента;
- настройка Cookie сохраняет выбор локально, но не управляет сторонней аналитикой;
- оплата, скачивание материалов и регистрация на мероприятия не подключены;
- содержимое снимков пока не редактируется через Gutenberg/ACF — оно пересобирается из статических HTML-файлов.

Следующий этап динамической натяжки описан в `docs/wordpress-content-template-map.md`: статьи переводятся в `post`, а кейсы, мероприятия и материалы — в отдельные типы записей и поля без изменения текущего дизайна и ЧПУ.
