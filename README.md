# FORMA hotel advisory

Статический многостраничный сайт Виталины Погорила о развитии продаж отелей. Реализован на HTML, CSS и JavaScript без фреймворков и сборщика.

## Локальный запуск

```powershell
python -m http.server 4173
```

После запуска открыть `http://localhost:4173/`.

## Проверка

```powershell
npm test
```

Тесты проверяют структуру 13 страниц, SEO-метаданные, юридические ссылки, точную палитру референса, подтверждённые контакты и услуги, формы, Cookie, адаптивные ограничения и чистую JavaScript-логику.

## Структура

- `index.html` — главная;
- `services.html`, `service.html` — услуги;
- `about.html` — миссия проекта и профессиональный путь;
- `projects.html`, `project.html` — кейсы и структура будущего кейса;
- `blog.html`, `article.html` — статьи, мероприятия и методические материалы;
- `contacts.html` — контакты и форма;
- `privacy.html`, `consent.html`, `cookies.html` — юридическая информация;
- `404.html` — страница ошибки;
- `assets/css/styles.css` — единая токенизированная дизайн-система;
- `assets/js/` — интерфейсные сценарии, форма и Cookie;
- `assets/images/` — локальные оптимизированные WebP-изображения;
- `robots.txt`, `sitemap.xml`, `site.webmanifest` — техническая SEO-основа.

## Перед публикацией

Нужно заменить `https://example.ru/` на финальный домен во всех HTML-файлах, `robots.txt` и `sitemap.xml`, а также предоставить:

- утверждённое название и логотип;
- точные ссылки на Telegram, MAX и Дзен;
- реальные проекты, цифры и отзывы;
- каталог, цены, оплату и выдачу платных материалов;
- endpoint или сервис отправки заявок;
- перечень фактически подключённых обработчиков данных;
- идентификатор аналитики, если она нужна.

На сайте указаны подтверждённые контакты: `+7 906 503-94-28` и `vitalinapogorila@yandex.ru`. Формы работают в демонстрационном режиме и не передают введённые данные. Социальные ссылки визуально отключены до получения точных URL. Юридические страницы являются рабочими шаблонами и требуют финальной проверки после выбора домена, хостинга, аналитики, сервиса заявок и платёжного решения.

## Изображения

Семь самостоятельных hospitality-изображений созданы встроенным ImageGen по цветовому настроению пользовательского референса. Референс использовался только как ориентир по палитре и атмосфере; его логотип, текст, фотография и композиция не копировались.
