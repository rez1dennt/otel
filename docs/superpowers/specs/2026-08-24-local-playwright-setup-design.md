# Локальная установка Playwright

## Цель

Сделать Playwright доступным непосредственно в проекте для последующих браузерных проверок без зависимости от внешнего браузерного инструмента текущей сессии.

## Согласованный вариант

- Установить последнюю стабильную версию `@playwright/test` как dev dependency.
- Установить только Chromium, достаточный для регулярной проверки Chrome/Edge и мобильных размеров.
- Не устанавливать Firefox и WebKit до появления отдельной задачи на полную кроссбраузерную проверку.
- Не запускать интерактивный генератор `npm init playwright@latest`, чтобы он не создавал демонстрационные тесты и не менял структуру существующего проекта.

## Изменения проекта

- `package.json` получает dev dependency `@playwright/test`.
- `package-lock.json` создаётся или обновляется npm.
- Файлы сайта, существующие Node-тесты и команды запуска не изменяются.
- Chromium устанавливается штатной командой Playwright в пользовательский системный кэш и не добавляется в Git.

## Проверка

1. `npx playwright --version` возвращает установленную версию.
2. `npx playwright install --list` показывает Chromium для текущей установки.
3. Короткий локальный запуск Chromium открывает страницу `about:blank` и завершается без ошибки.
4. `npm test` сохраняет зелёный результат существующего набора тестов.
5. `git diff --check` не выявляет ошибок форматирования.

## Не входит в задачу

- Создание постоянного набора E2E-тестов и `playwright.config`.
- Установка Firefox и WebKit.
- Настройка CI/CD.
- Изменение разметки, CSS или JavaScript сайта.
